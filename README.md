# ארכיון קרנית שמש

אתר סטטי בעברית, מותאם לטלפון. קבצי האתר נמצאים בשורש המאגר.

## הפעלה

אין צורך בהתקנה או בבנייה. אפשר להעלות את קובצי השורש ואת תיקיית `assets` לכל אחסון סטטי. סיסמת הכניסה הנוכחית: **פוצץ**.

## GitHub Pages

1. קובצי האתר, כולל `.nojekyll`, כבר נמצאים בשורש המאגר.
2. ב־Settings → Pages בחרו Deploy from a branch, את הענף הראשי, ו־`/ (root)`.
3. שמרו והמתינו לסיום הפריסה. GitHub יציג את כתובת האתר.
4. בדקו את הכתובת בטלפון שאינו מחובר לחשבון GitHub ורק אז צרו QR לכתובת הסופית.

כל כתובות הנכסים יחסיות, כך שהאתר מתאים גם לנתיב משנה של GitHub Pages.

## עריכה

- `content.js`: סיסמה, תיקים אישיים, פרסים, תחזיות ותמונות.
- `style.css`: עיצוב הבסיס והאפקטים של הארכיון.
- `studio.css`: עיצוב שקיעה בהשראת מיאמי, פונט Karantina והתאמות מובייל. נטען אחרי עיצוב הבסיס.
- `hub.js`: חדר הבקרה והניווט בין ששת האגפים.
- הפונט המקורי Karantina נטען מקומית מתוך `assets`, ללא תלות בשירות פונטים חיצוני.
- `app.js`: כניסה, נעילה, חיפוש, חלונות תיקים, סימולציה וגלריה.
- `index.html`: מבנה האתר והטקסטים הראשיים.

### תמונות

הוסיפו את התמונות לתיקיית `assets/photos`, ועדכנו ב־`content.js` את `photos`, לדוגמה:

```js
photos: [
  {src:'assets/photos/01.jpg', title:'ערב אצל החבורה', category:'ביחד', alt:'חברי הקבוצה יושבים יחד'}
],
```

הגלריה תופיע אוטומטית עם סינון לפי קטגוריות, פתיחה בגודל מלא, חיצים ומקלדת. ללא תמונות מוצג מסך המתנה מכוון. התמונות אינן מועלות דרך הדפדפן ואינן נשמרות במכשיר המבקר.

הסיסמה היא אפקט עיצובי בלבד: היא וקובצי האתר זמינים בקוד. אינה מגינה על התוכן או על התמונות. אין כאן איסוף מידע, אנליטיקה או שרת. מצב הכניסה נשמר רק ללשונית הפעילה באמצעות sessionStorage. כפתור יאנקו פותח את הסרטון הרשמי ביוטיוב בלשונית נפרדת.

התוכן מבוסס על הספר שסופק. כל התיקים מנוסחים ברוח הספר; אין מדובר במסמכים רשמיים. לרם ולאיליי אין בספר תיק מפורט, והאתר מציין זאת.

## זיכרונות מהצ׳אט

- `memories-data.js` מכיל 18 ציטוטים נבחרים ונתונים מצטברים בלבד. לכל ציטוט כותב, תאריך ושעה. הכתיב המקורי נשמר; הכותרת היא תוספת עריכתית.
- `memories.js` מוסיף רגע יומי לפי התאריך המקומי (מתחלף גם אחרי חצות), שיתוף טקסט עם חלופת העתקה, ציר זמן מסונן לפי שנים, נפח רשומות שנתי ונספחים לתיקים שניתן להתאים בבירור לשמות בצ׳אט.
- הייצוא שנבדק מכסה 03.05.2022–25.10.2026. הוא מכיל טקסט בלבד, ולכן אין התאמה אוטומטית בין התמונות באתר לבין אירועים או תאריכים בצ׳אט.
- סך 137,458 הרשומות כולל כותרות תאריך ושעה תקינות, לרבות מדיה, הודעות מערכת ורשומות ריקות. תבנית התאריך במקור היא חודש/יום/שנה; שעות כוללות ספרה אחת או שתיים. הודעות המשך מצורפות לרשומה הקודמת. הספירה מחליפה את נתוני הייצוא הקודמים.
- נספרו 11,940 רשומות שתוכנן המדויק הוא ״סטיקר הושמט״ ו־168 רשומות עם ״פוצץ״ כמילה עצמאית. אין להסיק מכך כמה יציאות בוטלו בפועל. נפח הפעילות אינו מספר הודעות טקסט בלבד; נתוני 2022 ו־2026 חלקיים.
- הייצוא המלא, ZIP, מספרי טלפון ותוכן שלא נבחר אינם נשמרים במאגר או נטענים בדפדפן. אין פנייה לשירות ניתוח חיצוני או שמירת נתוני מבקרים. הוספת זיכרון נעשית למערך `quotes` עם מזהה ייחודי; אין להעלות את קובץ המקור לאתר.

## מבצע: יוצאים היום

האגף `#simulation` מכיל משחק בחירות בן שש תחנות במקום הסימולציה הליניארית. לכל בחירה זמן, סבלנות ומוכנות; מציאת רכב, מסלול רגלי והיעד משפיעים על שישה סיומים אפשריים. המדדים חסומים בין 0 ל־100 והשעון מציין מעבר לחצות.

- `mission-engine.js`: חוקים דטרמיניסטיים ללא תלות בדפדפן. התחלה חדשה מאפסת את כל הבחירות; ניווט לאגף אחר וחזרה משאיר את הסבב הפעיל.
- `mission.js`: ממשק, מפה, יומן החלטות, ציטוטי מקור ממבחר `memories-data.js`, שיתוף וכרטיס תוצאה להורדה כ־SVG. הסיפורים והתגובות הם עיבוד משחקי, ומסומנים בנפרד מהציטוטים האמיתיים.
- `mission.css`: העיצוב והתאמות לנייד ולתנועה מופחתת. האיור החדש נשמר מקומית ב־`assets/mission/miami-night.png`; הוא איור למשחק ואינו תמונה מהחבורה.
- רק השיא המספרי נשמר ב־localStorage תחת `karnit-mission-best`. ללא אחסון זמין המשחק ממשיך לפעול. שיתוף והורדה נעשים רק בלחיצה, ללא שירות חיצוני.
- בדיקת החוקים: `node tests/mission-engine.test.cjs`. הבדיקה מכסה את כל 729 מסלולי ההחלטות, נגישות כל ששת הסיומים, גבולות המדדים, אי־שינוי מצב קודם, בחירות לא חוקיות ומעבר לחצות.
